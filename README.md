# Juneteenth: Freedom Day Tribute

Welcome! This project is a modern, accessible, and celebratory landing page for **Juneteenth**—a day honoring Black liberation, resilience, and culture in the United States.  
Built for the [Frontend Challenge - June Celebrations, Perfect Landing: June Celebrations](https://dev.to/challenges/frontend-2025-06-04).

## ✨ About This Project

This landing page is designed to:
- **Educate** visitors about the history and significance of Juneteenth
- **Celebrate** Black culture and community with vibrant, inclusive visuals
- **Encourage** everyone to participate, learn, and share their stories
- **Promote** accessibility and representation in web design

## 🌈 Features

- **Animated hero section** with welcoming, bold visuals
- **Interactive timeline** that tells the story of Juneteenth
- **Celebration ideas** for honoring Juneteenth in your own way
- **Socials section** with links and hashtags to uplift community voices
- **Accessible & responsive**: works great on all devices and for all users

## 🧑🏾‍🤝‍🧑🏼 Inclusivity & Accessibility

We believe everyone should be able to celebrate and learn about Juneteenth.  
This site is designed with:
- High-contrast colors and large, readable fonts
- Keyboard navigation and semantic HTML
- Alt text and ARIA labels for screen readers
- Responsive layout for mobile, tablet, and desktop

If you find any accessibility issues or have suggestions, please [open an issue](https://github.com/yourusername/juneteenth-landing-page/issues) or [contact us](mailto:your@email.com).

## 🚀 Getting Started

**Clone the repo:**
```bash
git clone https://github.com/yourusername/juneteenth-landing-page.git
cd juneteenth-landing-page
```

**Open in your browser:**  
Just open `index.html` in your web browser.

**Or run locally with a simple server:**
```bash
# Python 3
python3 -m http.server 3000
# or with Node.js
npx serve .
```
